Opravné vydání Lazurio App (Alpha) pro Windows. Aplikace na kanálu Stabilní se aktualizuje sama.

**Opraveno**

- **Prázdné okno po zhasnuté obrazovce.** Když se aplikace spustila nebo běžela při zhasnuté obrazovce, mohla okna Lazurio App i Agent Desktop zůstat po rozsvícení prázdná, dokud se aplikace neukončila a nespustila znovu. Aplikace se teď pokusí okno sama znovu vykreslit, když je v popředí: po rozsvícení obrazovky, odemčení počítače, nebo když s oknem začnete pracovat, zpravidla do 20 sekund. Neuloženou práci ve stránce přitom nemaže.

**Pokud se to přesto stane**

- Zvolte v okně Zobrazit → Znovu načíst stránku, nebo aplikaci ukončete přes ikonu v oznamovací oblasti vedle hodin a spusťte ji znovu. Pošlete nám prosím text z Zobrazit → Stav aplikace → Kopírovat stav.

**Co zatím ne**

- **Ovládání počítače agentem (Agent Desktop):** vypínač v aplikaci zatím nefunguje. Nechte ho prosím vypnutý, dokud vám nedáme vědět.
- **Podpis:** instalátor ani aplikace nemají podpis Microsoftu. Windows při první instalaci ukáže upozornění SmartScreen („Systém Windows ochránil váš počítač“): zvolte Další informace a pak Přesto spustit. Se zapnutou funkcí Smart App Control Windows aplikaci bez podpisu nespustí.
- **Mac:** sestavení pro Mac je jen zkušební a samo se neaktualizuje.

Nejnovější stabilní instalátor je vždy na adrese https://github.com/Lazurio/lazurio-app/releases/latest/download/Lazurio-App-Setup.exe.

Chyby a dotazy hlaste prosím svému kontaktu v Lazuriu.
