Opravné vydání Lazurio App (Alpha) pro Windows. Aplikace na kanálu Stabilní se aktualizuje sama.

**Opraveno**

- **Okno aplikace už nezůstane prázdné, když se aplikace spustí při zhasnuté obrazovce:** po jejím rozsvícení se samo vykreslí, zpravidla do 20 sekund.
- **Prázdné okno po probuzení displeje.** Když se aplikace spustila nebo běžela při zhasnutém displeji, mohla okna Lazurio App i Agent Desktop zůstat po probuzení prázdná, dokud se aplikace neukončila a nespustila znovu. Aplikace teď okno v popředí po probuzení, odemčení nebo když s ním začnete pracovat, sama znovu vykreslí. Neuloženou práci ve stránce přitom nemaže.

**Pokud se to přesto stane**

- Zvolte v okně Zobrazit → Znovu načíst stránku, nebo aplikaci ukončete přes ikonu v oznamovací oblasti vedle hodin a spusťte ji znovu. Pošlete nám prosím text z Zobrazit → Stav aplikace → Kopírovat stav.

**Co zatím ne**

- **Ovládání počítače agentem (Agent Desktop):** vypínač v aplikaci zatím nefunguje. Nechte ho prosím vypnutý, dokud vám nedáme vědět.
- **Podpis:** instalátor ani aplikace nemají podpis Microsoftu. Windows při první instalaci ukáže upozornění SmartScreen („Systém Windows ochránil váš počítač“): zvolte Další informace a pak Přesto spustit.
- **Mac:** sestavení pro Mac je jen zkušební a samo se neaktualizuje.

Nejnovější stabilní instalátor je vždy na adrese https://github.com/Lazurio/lazurio-app/releases/latest/download/Lazurio-App-Setup.exe.

Chyby a dotazy hlaste prosím svému kontaktu v Lazuriu.
