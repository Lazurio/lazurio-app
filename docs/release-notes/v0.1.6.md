Vydání Lazurio App (Alpha) s plným ovládáním počítače pro Agent Desktop. Na Windows se aplikace na kanálu Stabilní aktualizuje sama, na Macu ji stáhněte a nainstalujte znovu.

**Nové**

- **Agent Desktop dává agentovi plné ovládání počítače.** Zapnutý vypínač teď znamená, že agent hýbe skutečnou myší, kliká, táhne a píše na klávesnici. Dokud agent pracuje, na počítači sami nepracujte, nebo ho nejdřív zastavte tlačítkem Zastavit v liště nahoře v okně. Zastavit ukončí i spojení agenta, takže se neprovede nic z toho, co agent poslal před stisknutím. Agent se pak připojí znovu sám a řádek v okně Agent Desktop to na chvíli ukáže. Dokud je vypínač zapnutý, může agent po novém připojení zase ovládat počítač. Aby nepokračoval, vypněte vypínač.
- **Chybějící síť Organizace řekne lišta nahoře.** Když síť Organizace na počítači chybí, ukáže to tenká lišta nad každou stránkou s tlačítkem Co dělat. Sloupec Stav se už sám neotevře.
- **Mac: oprávnění po aktualizaci.** Když Nastavení systému ukazuje oprávnění pro Lazurio App jako zapnuté, ale okno Agent Desktop píše Nepovoleno, okno teď řekne, jak ho obnovit: v seznamu aplikaci odeberte tlačítkem − a přidejte znovu tlačítkem +.

**Opraveno**

- Po Zastavit uprostřed tahu myší už nezůstane stisknuté tlačítko myši.
- Vypínač Agent Desktop se už sám nevypne kvůli jedné nepovedené kontrole staré aplikace Lazurio Agent Desktop na zatíženém počítači.

**Co zatím ne**

- **Záložky se nepamatují.** Po spuštění aplikace je otevřená jen první záložka s Přehledem.
- **Záložku zatím nejde přetáhnout** na jiné místo v pruhu ani do samostatného okna. Řádek s adresou stránky zatím také není.
- **Podpis:** instalátor ani aplikace nemají podpis Microsoftu ani Applu. Windows při první instalaci ukáže upozornění SmartScreen („Systém Windows ochránil váš počítač“): zvolte Další informace a pak Přesto spustit. Se zapnutou funkcí Smart App Control Windows aplikaci bez podpisu nespustí. Na Macu zvolte při prvním otevření v Nastavení systému → Soukromí a zabezpečení „Přesto otevřít“.
- **Mac se sám neaktualizuje.** Každou novou verzi pro Mac je potřeba stáhnout a nainstalovat znovu, dokud aplikace nebude mít podpis Applu. Na Macu povolíte obě oprávnění pro Agent Desktop znovu po každé nové verzi. Při prvním spuštění nové verze se Mac také zeptá na Klíčenku („Lazurio App (Alpha) wants to use your confidential information stored in “Lazurio App Safe Storage”…“): zadejte heslo k Macu a zvolte Vždy povolit (Always Allow).

Nejnovější stabilní instalátor pro Windows je vždy na adrese https://github.com/Lazurio/lazurio-app/releases/latest/download/Lazurio-App-Setup.exe.

Chyby a dotazy hlaste prosím svému kontaktu v Lazuriu.
